# 代码分支说明

分支按模型或训练实现区分。学习率、有效batch、训练步数、源数课程和续训检查点的变化，记录在实验protocol中，不各建代码分支。

| 分支 | 改了什么 | 状态 |
| --- | --- | --- |
| `main` | 保留上游ReCamMaster代码 | 官方基线 |
| `single-view-v2v` | 单源纯V2V、空文本缓存、确定性采样、完整训练状态保存与恢复 | 早期单源实现；不是在多视角网络上只喂一个源 |
| `multiview` | 可变多源输入、密集Plücker相机条件、共享时间坐标、课程采样及选择性激活重算 | 当前多视角代码线 |
| `experimental/microbatch` | 合并单卡多个样本，修复B>1时间调制广播并保持逐样本加权损失 | 性能实验，未用于正式训练 |

当前多视角训练仍采用每卡microbatch1。单卡合批实验在H100上1～3源慢23%～31%，4源OOM，因此不合入正式代码线。具体条件与限制见该实验分支的docs/microbatch.md。

BS16/BS40、单源课程/多源课程、不同学习率与训练步数并不自动构成新的模型版本。关键实现已有代码线可复用时，只保留独立实验协议、检查点和结果。关闭确定性、恢复策略等若实际涉及代码变化，应保留准确代码快照；需要作为可复用功能维护时再整理成实现提交，不能把它们误称为全部仅有命令参数差异。

早期Plücker v1/v2仅作为设计历史保留在docs/history；它们未进行相同的正式长训，不列作与当前模型等价的训练结果版本。原始源码归档仍在个人实验目录。

GitHub保存可阅读的源码及使用说明，不保存按服务器绝对路径复制的历史目录树、环境清单或逐次实验protocol。个人持久目录负责实验恢复记录与原始快照。
